# AtCoder 復習支援アプリ
## 概要
AtCoderで取り組んだ問題を記録・管理し、復習に役立てるためのWebアプリケーションです。
問題名、問題のURL、学習メモを保存することで、過去に取り組んだ問題や学習内容を整理できるようにすることを目的としています。
現在、Pythonを用いたWebアプリケーション開発の学習を兼ねて個人開発しています。　
！！まだ開発中です！！

## 開発背景
競技プログラミングを学習する中で、過去に解いた問題や、その問題に必要な知識を整理しておきたいと考え、開発を始めました。
主に、Pythonによるプログラミングの経験を生かしながら、Webアプリケーションの仕組みやデータベースの扱い方について理解を深めることも目的としています。

## 使用技術
- 言語：Python、HTML、SQL
- Webフレームワーク：Flask
- データベース：SQLite
- バージョン管理：Git、GitHub

## 実装済みの機能
- 問題名、URL、学習メモの登録
- 登録した問題の一覧表示
- 登録済みの問題の編集
- 登録済みの問題の削除
- SQLiteを利用したデータの保存

## 実行方法
Pythonがインストールされている環境で、次のコマンドを順番に実行します。
1. `python -m pip install Flask`
2. `python db.py`
3. `python -m flask --app app run`

起動後、ブラウザから `http://127.0.0.1:5000` にアクセスしてください。
